# BanglaDoc.com (বাংলাডক)

> বিনামূল্যে অনলাইন বাংলা চুক্তিপত্র ও দরখাস্ত তৈরির আধুনিক ওয়েব প্ল্যাটফর্ম।

BanglaDoc is an open, client-side web utility that allows Bangladeshi citizens and businesses to generate printable, standardized legal agreements (*Chuktipotro*) and official administrative applications (*Dorokhash*) in under 60 seconds with zero data tracking.

## 🌟 Key Features
- **Client-Side Privacy:** 100% of document processing runs locally in the user's browser. No private NID, phone number, or personal details are ever sent to a database.
- **Dynamic Bangla Currency Converter:** Automatic numeric-to-Bengali words converter (`৫০,০০০` ➔ *"পঞ্চাশ হাজার টাকা মাত্র"*).
- **Pixel-Perfect A4 Printing:** Pre-configured `@media print` stylesheets designed specifically for A4 documents without website headers, footers, or clutter.
- **Zero Operating Cost:** Static HTML/CSS/JS architecture designed for Cloudflare Pages edge deployment.

## 📄 Included Generators
1. **বাসা ও ফ্ল্যাট ভাড়ার চুক্তিপত্র** (`rent-agreement.html`) - Residential tenancy agreement with advance deposit, notice period, and utility clauses.
2. **থানায় সাধারণ ডায়েরি (জিডি) আবেদন** (`police-gd.html`) - Police General Diary application with presets for lost mobile phones, Smart NIDs, and educational certificates.
3. **টাকা ধার ও ঋণ অঙ্গীকারনামা** (`money-loan.html`) - Personal loan promissory note with repayment schedule and witness signature blocks.
4. **বাণিজ্যিক ও দোকান ভাড়ার চুক্তিপত্র** - Commercial lease agreement format.

## 🛠️ Tech Stack
- **HTML5 & Semantic SEO:** Structured Data (`FAQPage`, `WebApplication` JSON-LD)
- **Vanilla CSS:** Forest Teal & Slate design tokens with Bangla typography (*Hind Siliguri* & *Kalpurush*)
- **Vanilla JS:** Zero-dependency, lightweight client-side state binding and number conversion
- **Hosting:** Cloudflare Pages (Global CDN with Dhaka edge routing)
